# Открытые вопросы: расхождения кода и ТЗ

Рабочий список. Источник требований — `docs/spec.md`. Сюда записываются расхождения кода и ТЗ, по которым ещё нет решения заказчика. Для каждого нужно выбрать одно: доработать код **или** изменить требование в ТЗ. После решения пункт получает статус и переносится в журнал изменений ТЗ (раздел 15).

**Статусы:** `открыт` — решения нет; `код` — решено дорабатывать код; `ТЗ` — решено изменить ТЗ; `закрыт` — сделано.

**Оговорка.** Список составлен 02.10.2026 чтением кода (`index.html`, `script.js`), а не прогоном критериев приёмки в браузере. Перед решением пункты стоит перепроверить на опубликованной странице: https://www.mylook365.de/
